# 🧮 Calculadora de IRPF

Aplicação web para calcular o **Imposto de Renda Pessoa Física (IRPF)** com base na renda mensal informada pelo usuário, aplicando as alíquotas e deduções oficiais da Receita Federal do Brasil.

## 📋 Sobre o projeto

Esta calculadora foi desenvolvida como projeto prático da disciplina **Engenharia de Software**, com o objetivo de demonstrar na prática o uso de ferramentas de versionamento, deploy contínuo e análise estática de código.

O projeto integra três ferramentas principais:

| Ferramenta | Função |
|---|---|
| **GitHub** | Versionamento e controle do código-fonte |
| **Vercel** | Deploy automático a cada push na branch `main` |
| **SonarCloud** | Análise estática e métricas de qualidade de código |

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout responsivo
- **JavaScript (Vanilla JS)** — lógica de cálculo do IRPF

Sem dependências externas — leve e acessível em qualquer navegador moderno.

## 📁 Estrutura do projeto

Calculadora-irpf/

## ▶️ Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/josiellyr8-byte/Calculadora-irpf.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Calculadora-irpf
   ```

3. Abra o arquivo `index.html` diretamente no navegador — não é necessário servidor ou instalação.
